# Hack-Accessibility

Building something that removes barriers and opens doors.

> Status: **ideation** — researching underserved accessibility gaps before committing to a direction.

## Principles

1. **Nothing about us without us.** Ground every feature in what disabled people actually
   ask for, not what we imagine they need.
2. **Works without a network and without an API key.** Core functionality is deterministic.
   AI enhances; it never gatekeeps.
3. **Accessible itself.** An accessibility tool that fails WCAG is a joke. Keyboard-first,
   screen-reader tested, respects `prefers-reduced-motion` and `prefers-contrast`.
4. **Free where it matters.** We target gaps where the existing option is expensive,
   proprietary, or abandoned.
